# Glossary

## API
A program interface that lets one system send requests to another system.

## Controller
A class that groups related API endpoints.

## Route
The URL pattern used to reach an endpoint.

## Endpoint
A specific HTTP method and route, such as `GET /api/contacts`.

## Request
Data sent to the API.

## Response
Data returned by the API.

## Model
A C# class that represents application data.

## DbContext
The EF Core class that manages database access.

## DTO
A Data Transfer Object used to send or receive API data.

## Migration
A tracked database schema change in EF Core.

## SQLite
A lightweight file-based database.

## Swagger
A tool for exploring and testing API endpoints in the browser.

## JSON
A common text format used for API request and response data.

## REST
A common style for APIs that uses HTTP methods such as GET, POST, PUT, and DELETE.
